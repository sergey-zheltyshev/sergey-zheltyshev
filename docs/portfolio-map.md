# Portfolio map

The projects form one connected engineering practice:

| Question | Project | Main artifact |
|---|---|---|
| Can the input be trusted? | Company Registry | Evidence-aware structured record |
| What is happening in the product? | Signal | Ordered user-level funnel |
| Can an action safely resume? | Workflow Automation | Durable process state |
| Where does the work belong? | Project Operations | Canonical item and attention projection |
| Can the interface stay simple? | Check-in | Compact entry and persistent workspace |

Problem framing, system modeling, implementation and verification are visible across every case. The portfolio favors inspectable behavior over unsupported impact claims.
