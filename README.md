# Sergey Zheltyshev

**Systems Analyst & Software Engineer**  
**From ambiguity to working systems.**

I turn unclear operational problems into explicit requirements, data contracts and working software. My focus is integrations, data quality and workflows where the meaning of a result matters as much as the code that produces it.

## Selected systems

### Company Registry · Reliable company records from conflicting sources

Normalize observations, validate company identity and resolve conflicting fields while preserving the evidence behind each decision. The module produces structured records with explicit review outcomes.

### Signal · Understand acquisition, activation and subscriptions

Turn event history into a consistent analytics report. Separate new and returning users, preserve each funnel's denominator and prevent overlapping channel entries from inflating conversion.
